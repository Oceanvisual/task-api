# 0004. Egress к LLM через forward-прокси

- Дата: 2026-09-30
- Статус: Accepted
- Источник: f8f5237 (fix(llm): egress через прокси для обхода geo-WAF провайдера)

## Контекст
Прод на VPS в РФ получал 403 от OpenRouter: geo-WAF режет RU-IP. С US-exit тот же ключ отдаёт 200.

## Решение
`Settings.llm_proxy_url`; `get_llm()` оборачивает sync/async openai-клиент в `DefaultHttpxClient(proxy=...)`.
Значение — только из секрета `LLM_PROXY_URL` (deploy.yml через `envs`, с экранированием `$` для compose).
Пусто = прямой выход.

## Альтернативы
- Перенос VPS за пределы РФ: не рассматривалось в коммите.

## Последствия
Ошибки провайдера логируются с реальным статусом (`_provider_error`). Падение прокси = падение LLM-части сервиса.
